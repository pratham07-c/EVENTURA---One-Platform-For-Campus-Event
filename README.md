# EVENTURA---One-Platform-For-Campus-Event
EVENTURA is a centralized campus event management platform for creating, approving, managing, and analyzing college events. It integrates registrations, QR-based attendance, volunteer management, finance tracking, feedback, automated certificates, and real-time analytics into one seamless workflow.

🚀 Key Features

- **Event Creation & Approval Workflow:** Multi-tier role permissions for students, faculty, and admins to propose and approve events seamlessly.
- **Registrations & Ticketing:** Custom registration forms with unique QR-code ticket generation for attendees.
- **QR-Based Attendance Tracking:** Fast and secure check-ins at event entry using scanner integration.
- **Volunteer & Task Management:** Assign roles, tracks, and duties to student volunteers with real-time status updates.
- **Finance & Budget Tracking:** Monitor venue costs, sponsorship funds, and ticket revenue with visual expense reports.
- **Automated Certificates:** Instant generation and emailing of customizable participation/appraisal certificates post-event.
- **Real-Time Analytics & Feedback:** Interactive dashboards tracking attendee turnout, demographics, and post-event survey insights.

---

## 🛠️ Tech Stack

- **Frontend:** React / Next.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / PostgreSQL
- **Authentication:** JWT / OAuth 2.0
- **Storage/Services:** Cloudinary (for media), Nodemailer (for emails/certificates)
